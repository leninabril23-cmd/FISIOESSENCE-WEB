# FisioEssence WEB

Sitio corporativo responsive con fotografías y videos suministrados.

## Abrir localmente
`npm start` y visitar http://localhost:3000

## Render (Web Service, Node)
- Root Directory: vacío si `package.json` está en la raíz del repositorio
- Build Command: `npm install`
- Start Command: `npm start`
